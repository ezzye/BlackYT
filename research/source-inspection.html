Upstream architecture points to a browser-first PoC with a clear native boundary

Inspected official NewPipe, NewPipeExtractor and LibreTube repositories. The PoC should remain a clean-room implementation: Python/yt-dlp resolves metadata and a fresh media URL; the browser plays the returned URL directly. Do not copy GPL application code.

NewPipe · 6f6b5fb

PlayerService.onCreate creates MediaSessionCompat and its connector; YoutubeHttpDataSource.makeConnection handles byte ranges, origin/referer, user agent and request headers. MediaSourceManager.getLoadedMediaSource resolves/caches sources and maps extraction/network failures. README documents groups and feeds.

Takeaway: native player requests have specialized HTTP behavior beyond what a PWA can set itself.

NewPipeExtractor · 8443c91

YoutubeStreamExtractor.getAudioStreams/getVideoStreams/getVideoOnlyStreams parse regular and adaptive formats into stream descriptors. VideoStream.java models URL, resolution, format and video-only status.

Takeaway: direct stream links are extraction results, with ongoing signature/player compatibility work.

LibreTube · caf18f6

NewPipeMediaServiceRepository configures a PoToken provider. Its getStreams calls StreamInfo.getInfo and maps metadata, direct audio/video streams and manifests. OnlinePlayerService.startPlayback fetches them; AbstractPlayerService is a MediaLibraryService owning the player/session. Room groups are filtered by channel IDs.

Full Local Mode means direct YouTube requests and IP exposure; observed repository singleton currently constructs the NewPipe service repository.

What this means for the PWA

Direct <audio>/<video> playback can request cross-origin media without giving JavaScript access to the response. Fetching/inspecting media bytes is CORS-controlled. Test seeking/range requests and codec support on each target browser.

Resolved Google video URLs may expire and can be sensitive to request/network identity. Re-resolve after expiry or playback failure; avoid treating a media URL as a permanent library identifier. If the local resolver and browser use different egress IPs, direct playback may fail.

Media Session can expose metadata and transport actions where supported; it does not provide the app-owned Android foreground service/session guarantees in NewPipe or LibreTube. A native wrapper is needed for that layer. Browser storage can still implement editable channel groups and filters.
