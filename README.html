BlackYT

A small Android PWA for selected public YouTube audio. The browser receives media directly from YouTube. A local Python helper handles search, metadata and short-lived stream addresses, without relaying media.

Run it

The environment is prepared on this Mac. From the repository folder:

./start.sh
# Open http://localhost:8765

Fresh setup requires Python 3.10+ and Deno or a supported Node runtime:

./setup.sh
./start.sh

For the current Wi-Fi phone test:

./start.sh --listen 0.0.0.0 --allow-host 192.168.1.228

The existing phone certificate is retained locally for private HTTPS:

./start.sh --listen 0.0.0.0 --port 8766 --allow-host 192.168.1.228 --cert .tls/server-cert.pem --key .tls/server-key.pem

Wi-Fi player · Private HTTPS player · Full offline report

Implemented

  • Music-category verification before playback and title/channel include/exclude filters.
  • Audio queue, next/previous, seeking and Media Session controls.
  • Installable PWA shell with offline interface; search and streams remain online.
  • Only HTTPS YouTube media hosts are accepted. There is no media-proxy endpoint.

The owner reported two-minute screen-off playback in Android Chrome, warning-free private HTTPS, successful Pixel 10 Pro XL installation and playback from the installed app. Queue changes while locked and headset outcomes were not separately confirmed.

Verify and review

.venv/bin/python -m unittest -v test_server

Focused backend and browser evidence is in evidence/. Pinned NewPipe, NewPipeExtractor and LibreTube source findings are in research/; no upstream application code was copied.

Private certificates and keys, the environment, usage records and generated ZIP are ignored by Git. Existing phone trust depends on the local files in .tls/ and the public CA files. No CA signing key was retained.

Prototype limits

The Mac helper must remain reachable; the phone and resolver should share the same internet exit. YouTube changes can interrupt this unofficial access route. Creator promotions inside a recording are not removed. The current local server certificate expires on 22 October 2026; a different LAN address needs a new certificate setup.

This repository is local. Publishing or deploying it is a separate action.
