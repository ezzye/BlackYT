BlackYT · Native Android

Find your next favourite.

BlackYT is a single Android app for finding and playing YT music links. Stream extraction and audio playback happen on the phone.

Public release: v0.3.1

Release

The public release is v0.3.1, with BlackYT-Android-v0.3.1.apk. Download the APK and this offline guide without GitHub sign-in.

Validation so far

The signed v0.3.0-native APK was installed on the Pixel 10 Pro XL and its installed APK hash matched the release file. Five unit checks passed, release lint reported zero errors with routine warnings, and direct native Googlevideo audio returned HTTP 200. The owner confirmed audible playback, continued playback with the screen locked, and automatic playback of the next queued song while locked. The owner also confirmed v0.3.0-native playback on mobile data with USB unplugged and continued playback while locked. v0.3.1 updates wording and disclaimer only on the same playback engine; these are not v0.3.1 device tests. The Mac and Termux are not playback dependencies.

Install the APK

  1. On your Android phone, open the public BlackYT release page. No GitHub sign-in is needed.
  2. Open the v0.3.1 release page and download BlackYT-Android-v0.3.1.apk.
  3. Open the downloaded APK. If Android asks, allow the browser or file manager to install apps, return to the installer, and tap Install.
  4. Open BlackYT from your launcher. The previous Chrome home-screen app called BlackYT Phone belongs to the older Termux setup.

Normal playback needs no Termux, Chrome, local server, Mac, account, or cloud relay.

Search and play

  1. Tap the search box. Enter a song or artist, or paste a YT link, then tap Search. There is no external Open or Share link action; paste the link into the search box.
  2. Music results only is checked initially. Uncheck it if a result you want is missing. Music classification depends on available YT metadata and is not guaranteed.
  3. Optionally enter comma-separated words in Include any words or Exclude any words. Include keeps a result when any included word appears. Exclude removes it when any excluded word appears. Matching uses the available title and channel text.
  4. Tap Play on a result to start it now, or Add to append it to the FIFO queue.
  5. Use Previous, Stop, Play/Pause, Next, and the seek bar in the player. Android notification and lock-screen controls use the native player session.

The queue lasts only for the current app session. Filter settings persist. There are no offline downloads and no sign-in.

If a song stops

Check that the phone is online and tap Retry current song. Retry obtains a fresh stream URL, which may help after a network change or when an earlier link expires. Some videos, including age-restricted or otherwise restricted items, may not be available.

Playback path

The phone requests YT data and streams audio directly from YT's Googlevideo host. BlackYT does not route audio through a cloud relay or request the YT player's separate ads. Promotions embedded in a recording remain part of that recording. YT may change its service and break search or playback.

About BlackYT

BlackYT is an independent educational project about making music easier to discover and enjoy. Its creator uses BlackYT to listen to songs they wrote and perform. The project aims to help students explore and learn about music regardless of socioeconomic circumstances, with fewer advertising interruptions and low running costs.

Build and signing

Source is GPL-3.0-or-later; see LICENSE and NOTICE. Build uses Java 17, Android SDK 36, Build Tools 35, Android Gradle Plugin 8.13.2, and Gradle 8.13.

From the Android source folder: ./gradlew assembleDebug, ./gradlew testDebugUnitTest, and ./gradlew lintRelease. Local release signing reads ../.local/android-signing.properties. Keep the signing properties and keystore private; updates must use the same key. Keep a protected backup in secure credential storage and a second encrypted, access-controlled location. Never place key material in a release, HTML file, or Git.
