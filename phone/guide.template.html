BlackYT · Pixel 10 Pro XL

Take BlackYT with you.

Your phone runs the player and the small search helper. YouTube supplies the audio directly to your phone. After this first setup, the Mac can be switched off.

1. Install Termux

On your Pixel, open the official F-Droid Termux page. Choose the suggested stable version 0.118.3, or use this direct APK download from F-Droid, then install and open it. You do not need the separate F-Droid app.

If Android asks, allow Chrome to install that downloaded app. Termux should open to a screen where you can type. If Termux is already installed from another source, stop here and check before replacing it: different sources use different signatures.

2. Copy the setup command

For this step only, keep the phone on the same Wi-Fi as the Mac. Open this guide on the phone at __GUIDE_URL__. Tap Copy setup command, switch to Termux, press and hold at its typing prompt, choose Paste, then press Enter.

The command downloads the phone package, checks its fingerprint, and installs it in Termux's private storage.

Setup first upgrades Termux packages together to keep their libraries compatible, then installs Python and Node. It can take several minutes and uses internet data. No purchase, YouTube sign-in, storage permission, or Termux:API companion is required.

3. Add the phone app

When setup finishes, Chrome should open http://127.0.0.1:8765/. Look for “Running on this phone.” near the bottom. If an older page appears after an update, reload it once after Chrome finishes updating the app shell. In Chrome, use the ⋮ menu → Add to Home screen → Install if offered.

Use the new BlackYT Phone icon. The earlier BlackYT icon at the 192.168 address still connects to your Mac. The phone address needs no custom certificate.

Keep Termux running while listening. In Android's app information for Termux, allow background activity or unrestricted battery use if that option is shown. Android can still stop background processes; restart the helper if needed.

4. Check it away from the Mac

  1. Turn the phone's Wi-Fi off so it uses mobile data.
  2. In BlackYT Phone, make a new search and play a result. Add a second track.
  3. Make the Mac unavailable, then lock the phone for two minutes and listen. Let the next track start too.

A fresh search tests the helper. A fresh play tests YouTube from mobile data. Continuing an already buffered song alone does not prove independence from the Mac.

If a stream stops when switching networks, tap Retry track. It requests a new YouTube link and tries to resume your position.

Daily use

Open Termux, type blackyt, and press Enter. It opens the local player. Keep Termux running, switch to BlackYT Phone, and put the phone in your pocket.

If you restart the phone or Android stops Termux, run blackyt again. To stop the helper, return to its Termux session and use Ctrl + C. The Termux CTRL extra key plus C does this.

Termux forwards audio locally on your phone. No cloud server or off-device audio relay is used. Your normal mobile data and battery use still apply. This unofficial YouTube route can change or be blocked. Creator messages inside the recording remain part of the audio.

After the phone version works, the temporary BlackYT local test CA - remove after testing can be removed from Android's user credentials if you no longer use the Mac version. Remove only that named certificate.
