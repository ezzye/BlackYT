What is built

  • Direct audio: the browser loads an HTTPS googlevideo.com stream. There is no media proxy, video hosting bill or YouTube iframe.
  • Music mode: search proposes candidates; Play checks YouTube's Music category and rejects other categories. This is metadata classification, not analysis of the sound.
  • Chosen interests: include/exclude phrases match the title and channel. Any include phrase can match; an exclusion takes precedence. Preferences stay in the browser.
  • Listening controls: Play, queue, next/previous, seek and Media Session controls. Expiring URLs are refreshed when needed.
  • PWA shell: app manifest, local icons, install guidance and offline interface. The service worker never caches streams or API responses.

No purchase was needed. The helper uses the free open-source yt-dlp resolver in an isolated environment. Python plus Deno or a supported Node runtime is needed when running it elsewhere.

  2. In Android Chrome, open http://192.168.1.228:8765.
  3. Search for Kevin MacLeod Carefree, leave Music selected, and tap Play. If autoplay is refused, tap Play on the native audio controls.
  4. Lock the screen for two minutes. Then try headset pause/resume and a queued next track.
  5. Use Export phone test evidence. Its event log omits raw stream URLs; manually report whether the locked-screen test worked.

The Wi-Fi preview uses HTTP. Full PWA installation requires a trusted HTTPS origin or localhost; accepting an untrusted certificate is not treated as a successful installation. USB forwarding to localhost or trusted private HTTPS can provide a later install test.

Phone and resolver should use the same internet exit. Signed stream URLs can depend on that address, so switching the phone to mobile data may fail even though direct delivery worked on Wi-Fi. No paid relay fallback is enabled.

What inspecting NewPipe and LibreTube taught us

Both Android projects use native media services and sessions. LibreTube's current source calls NewPipeExtractor and maps its stream data into Android playback sources. NewPipe's HTTP data source also controls range and request headers. A browser has different controls, so this proof of concept uses an original web interface and a small metadata-only yt-dlp helper. No upstream application code was copied.
