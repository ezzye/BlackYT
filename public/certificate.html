First, save the certificate.

Open this page in Chrome on your phone, then tap the button below. It should download a file named blackyt-local-ca.cer.

Download certificate

DER certificate · 870 bytes · Same certificate as the earlier .crt file; its fingerprint has not changed.

In Chrome, open ⋮ → Downloads and look for blackyt-local-ca.cer. Certificate installation is a separate step in Android Settings.

Once the file is saved

  1. Open Settings → Security & privacy → More security & privacy → Encryption & credentials → Install a certificate. Google also calls the middle section More security settings in some Pixel guidance.
  2. Choose CA certificate. Review Android's trust notice, then select the downloaded blackyt-local-ca.cer from Downloads.
  3. The certificate name is BlackYT local test CA - remove after testing.
  4. Open BlackYT over HTTPS. It should open without a certificate warning. Then use Install app.

On Android 11 and later, CA installation must happen through Settings. Android documentation · Google's Pixel menu guide.
