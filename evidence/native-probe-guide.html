BLACKYT · NATIVE PHONE CHECK

Check audio access on the phone

This runs a small Python probe in the existing BlackYT Termux environment. It checks two tracks using the phone’s own connection and requests at most 4 KB per response.

Before you start

  1. Keep the phone connected to this computer by USB.
  2. In the existing Termux session, press Ctrl+C once to stop the foreground BlackYT process.
  3. Copy the command below, paste it into that same Termux session, and press Enter.
  4. Read the two result lines in Termux. The saved evidence is at ~/blackyt/native-probe-result.json.

The probe does not restart BlackYT. You can restart it after reviewing the result. The report is also sent over the USB-forwarded local connection when available.

Copy this command into Termux

curl -fsS http://127.0.0.1:8767/native-probe.py -o "$TMPDIR/blackyt-native-probe.py" && echo "5f38a03a8ce2fbfddbe0b7f79568aa644cdbd527e37a7e37d48fd1ad48467ca2 $TMPDIR/blackyt-native-probe.py" | sha256sum -c - && "$HOME/blackyt/.venv/bin/python" "$TMPDIR/blackyt-native-probe.py"

Keep USB connected during the probe. No Wi-Fi is needed for the phone-to-computer report; audio access uses the phone’s active internet connection. Only short status, MIME type, byte count, media host and header mode are reported.
